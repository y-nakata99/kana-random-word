# Web App Idea Factory (Template)

このリポジトリは、アイディアを最小操作で Web アプリケーションとして形にするためのテンプレートです。

目的：
・アイディアを簡単・スピーディに Web アプリケーションにする
・PR ベースで安全に開発を進める
・codex を用いた実装を前提とする

前提：
・GitHub + Vercel を利用する
・main ブランチは常に本番として扱う

開発フロー概要：
1. アイディアを整理する
2. codex に実装を依頼する
3. Pull Request を確認して main にマージする
4. Vercel により自動デプロイされる

ブランチ運用：
・main：本番
・codex/<slug>：作業ブランチ

## 追加したアプリ機能

ひらがな（50音）・カタカナ（50音）・アルファベットから文字種を選び、3〜7文字の「単語（文字列）」を生成するシンプルな Web アプリを追加しました。

### 使い方

1. `index.html` をブラウザで開く（または簡易サーバーで配信する）
2. プルダウンで文字種（ひらがな / カタカナ / アルファベット）を選ぶ
3. 「生成」ボタンを押す
4. 生成結果の領域にランダム文字列が表示される
5. 必要に応じて「コピー」ボタンでクリップボードにコピーする
